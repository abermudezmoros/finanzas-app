# Finanzas

App móvil (PWA) para apuntar gastos, ingresos, reembolsos, traspasos e inversiones en una hoja de Google Sheets.

- `index.html`: la app. Se instala en la pantalla de inicio desde el navegador.
- `apps-script/Codigo.gs`: el script que va dentro de la hoja (Extensiones > Apps Script) y recibe los movimientos.

La URL del script y la clave se introducen en Ajustes dentro de la app y solo se guardan en el móvil. Este repositorio no contiene datos personales.
